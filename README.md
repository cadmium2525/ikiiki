# いきてるせかい

企画書 v0.3 に沿った、3区画の2Dアクション試作。少し不気味でかわいい草原で、生き物の習性を使って進みます。

ブラウザで遊ぶ：[いきてるせかい](https://cadmium2525.github.io/ikiiki/)

## 起動

Node.js 22 以降で実行してください。

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。スマホから試す場合は `npm run dev -- --host 0.0.0.0` で起動し、同じWi-Fi内からPCのIPアドレスと表示されたポートにアクセスしてください。

## 操作

左右 / A・D で移動、Space / Z でジャンプ、X でちょっかい、R でリトライ、Esc でポーズ。ジャンプは長押しで高さが変わります。タッチ端末は横向きで画面下のボタンを使います。

## 試作の内容

- 練習・誘導・複合の3区画。区画ごとに復帰し、生物と破壊した壁を初期化。
- ビビリブロックは接近や刺激から逃げ、壁ぎわで止まります。
- イカリトゲは0.65秒の予備動作後に突進し、ひび割れた壁を破壊します。疲労中も触れると危険です。
- ちょっかいと共通イベント（Sight / Provoke / Sound / Impact / Touch）、連鎖上限。
- 120Hz固定ステップ、コヨーテ0.08秒・先行入力0.10秒、約0.45秒で復帰。
- 肌・髪・服の色変更、音ON/OFF、区画到達状況をlocalStorageに保存。ブラウザのデータ消去で失われ、他端末と同期しません。
- 自作の手続き描画ピクセルアートと合成効果音。外部画像・音源・Webフォントは使用していません。

## 構成と確認

`src/simulation.ts` がゲームルール、`src/levels.ts` が地形、`src/renderer.ts` がPhaser描画、`src/main.ts` が入力・画面・保存を担当します。

```sh
npm test
npm run build
npm run preview
```

## 公開

`dist` は静的ファイルです。GitHub Pages の Source に GitHub Actions を使い、main へのpushで同梱ワークフローがテスト・ビルド・公開します。相対base設定のため `/ikiiki/` 配下の画像・スクリプトの読み込みに対応します。

## 今後の確認

iOS Safari / Android Chrome の実機操作、初見プレイヤーによる難易度調整は別途必要です。ゲームパッド、追加生物、ボス、BGM、部位別衣装はこの試作の範囲外です。
